# oh-StarTrek-LCARS

虎鲸笔记（Orca Note）的 LCARS 风格插件，提供**设置钉选**功能——将常用设置项固定到编辑器侧边栏，一键切换。

## 背景

**LCARS**（Library Computer Access and Retrieval System，图书馆计算机访问与检索系统）是《星际迷航》（Star Trek）中星际舰队使用的计算机操作系统界面风格，以圆角面板、鲜明的色彩分区和未来感设计著称。

oh-StarTrek-LCARS 是虎鲸笔记的 LCARS 主题插件系列，灵感来源于星际迷航美学，旨在为笔记工具带来独特的视觉体验和高效的工作流增强。

## 功能

### 设置钉选

将虎鲸笔记设置面板中的开关类型设置钉选到编辑器侧边栏：

1. 打开设置面板（`Ctrl+,`）
2. 在任意开关设置项右侧点击 `+` 按钮
3. 从图标选择器中挑选一个图标
4. 该开关即出现在编辑器侧边栏，点击即可切换

**支持钉选的设置**：
- 虎鲸笔记自身的开关设置（如 24小时制、拼写检查、自动下载网络图片等）
- 其他插件的布尔类型设置（如 oh-StarTrek、tana-tag-color、task-planner 等）

### 图标选择器

- 1000+ Tabler Icons 可选
- 搜索过滤快速定位
- 模仿虎鲸原生图标选择器风格

### 调试模式

在插件设置面板中开启「调试模式」后，每次切换侧边栏开关时会在控制台打印详细日志：

```
[SettingsPin] 开关切换: oh-StarTrek.查询字体统一化 (queryFontUnifyMode) false → true
```

## 安装

将插件文件夹放入虎鲸笔记插件目录，重启虎鲸笔记即可。
