# oh-StarTrek-LCARS

> *"Computer, display user preferences."*  
> *"Preferences pinned to side panel. Ready for quick access."*

让虎鲸笔记（Orca Note）化身星际舰队终端——**设置钉选**功能，一键将常用开关锁定至编辑器侧边栏，指尖轻触即可切换。

---

## 星际传承

**LCARS**（Library Computer Access and Retrieval System），星际联邦的计算机界面标准，以其流线面板、鲜明分区与未来美学闻名于银河。

oh-StarTrek-LCARS 将这份星舰基因注入虎鲸笔记，从视觉风格到交互体验，让每一次设置调整都仿佛在企业号舰桥上执行指令。

---

## 核心功能

### 📌 设置钉选

**三步锁定，即时切换：**

1. 唤出设置面板（`Ctrl+,`）
2. 点击任意开关旁的 `+` 钉选按钮
3. 从千余图标中择一枚专属标识

自此，该开关便驻守于编辑器侧边栏，触手可及。

**兼容范围：**
- 虎鲸原生设置（24小时制、拼写检查、自动下载网络图片……）
- 第三方插件布尔开关（oh-StarTrek、tana-tag-color、task-planner 等）

### 🎨 图标选择器

- **1000+ Tabler Icons** 覆盖工作流场景
- 实时搜索，秒速定位
- 原生风格界面，无缝融入虎鲸生态

### 🔧 调试模式

插件设置中开启后，控制台将记录每次切换详情：

```
[SettingsPin] 开关切换: oh-StarTrek.查询字体统一化 (queryFontUnifyMode) false → true
```

适合开发者追踪设置变更，或普通用户了解插件行为。

将插件文件夹置于虎鲸笔记插件目录，重启应用即生效。
